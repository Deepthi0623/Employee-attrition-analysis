# Employee Attrition Analysis

## Overview
Analyzed employee attrition using Tableau to help HR teams understand and reduce employee turnover.

## Dataset
IBM HR Analytics Employee Attrition Dataset (1,470 employees)

## Key Findings
- Overall attrition rate: 16.12% (237 out of 1,470 employees)
- Sales department had the highest attrition
- Employees working overtime showed significantly higher attrition
- Early-tenure employees (1–2 years) showed the highest resignation rates
- Male attrition was higher than female attrition
